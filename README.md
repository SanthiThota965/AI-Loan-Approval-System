# AI Loan Approval System

An AI-powered Loan Approval Prediction System built using Machine Learning, Flask, SQLite, HTML, CSS, and JavaScript.

## Features

* AI-Based Loan Eligibility Prediction
* Dynamic Approval Percentage
* EMI Calculator
* Customer Data Storage using SQLite
* Modern Responsive UI
* Application History Management
* Real-Time Loan Analysis

## Technologies Used

* Python
* Flask
* Machine Learning (Random Forest)
* SQLite
* HTML
* CSS
* JavaScript
